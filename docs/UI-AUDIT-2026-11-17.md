# Audit dan refonte UI Hayatun

## Arah

Overhaul visual disetujui melalui permintaan langsung pengguna. Next.js, React, Outfit self-hosted, CSS native dipertahankan. Tidak menambah dependency. Brand rose #9D174D tetap; warna aksi disatukan. Canvas netral dingin, surfaces 16px, kontrol 8px, pills/badges penuh. Variance 6, motion 3, density 4. Tema mengikuti sistem untuk seluruh halaman.

## Temuan dan perubahan

- Beranda hanya judul dan grid: ditambah hero fotografi, proposisi singkat, CTA menuju koleksi, hierarki koleksi.
- Canvas pink dan aksi hijau bersaing: token netral dengan satu aksen rose; warna status tetap semantik.
- Shell toko tipis: container header, footer brand, skip link dan target main.
- Formulir kurang terkelompok: panel terpusat untuk formulir langsung, label dan focus state tetap.
- Admin minim hierarki: heading separator, tabel dengan header netral, active nav lebih tegas, safe-area navigasi bawah.
- Menu admin selalu aktif di Verifikasi: client leaf membaca pathname dan mengelompokkan rute turunan.
- Selector .steps checkout tertimpa timeline pesanan: checkout dipisah ke .checkout-steps.
- Dark mode tidak ada: token sistem dengan kontras teruji; invoice tetap dokumen putih siap cetak.

URL, label navigasi utama, logo teks, field, legal copy, mekanisme sesi dan API tidak diubah.

## Verifikasi

- `npm run lint`: lulus.
- `npm run typecheck`: seluruh workspace lulus.
- `npm -w apps/web run build`: lulus sebelum pemeriksaan browser; ulangi untuk snapshot akhir.
- `node apps/web/scripts/check-redesign.mjs`: beranda dan login, light/dark, lebar 320/768/1280, axe WCAG 2.1 AA, overflow dan runtime error lulus. API fixture terisolasi; tidak menyentuh DB.
- `npx vitest run --project ops ops/admin-nav.test.ts`: lulus; satu tes mencakup 16 pemetaan rute.
- Screenshot: `test-results/redesign/` (diabaikan Git). Desktop light, mobile dark dan login desktop ditinjau visual.
- Tes a11y lama diperbarui untuk kontrak hero/canvas baru tanpa menurunkan ambang kontras/ukuran sentuh.

## Batas verifikasi dan tindak lanjut

Full `npm test` gagal: suite operasi bergantung shell Linux dan suite API membutuhkan layanan DB/queue. Bukan bukti regresi UI, tetapi suite penuh belum hijau. E2E transaksi nyata belum dijalankan. Lighthouse belum dijalankan; tidak mengklaim target Core Web Vitals tercapai. Admin/checkout mendapat token bersama dan perbaikan khusus, belum seluruh rute diperiksa browser.

Build/dev memperingatkan kerentanan versi Next.js. Perlu audit dan upgrade keamanan terpisah sebelum deployment. Node 25 memicu warning engine Vitest; gunakan Node 24 LTS sesuai CI.

Audit juga menemukan panel verifikasi mobile belum menahan fokus dan error field belum memindahkan fokus ke field pertama. Tidak diubah diam-diam dalam refonte visual ini; perlu perbaikan perilaku teruji tersendiri.

## Git

Direktori awal tidak memiliki `.git`. Repositori lokal diinisialisasi untuk memenuhi permintaan commit. Commit pertama adalah snapshot sumber aplikasi termasuk refonte, bukan diff terhadap riwayat yang tidak tersedia. Tidak ada push atau remote baru.
